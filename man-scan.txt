### 🔍 Troubleshooting

1. Check Docker containers:
   docker compose --env-file ~/caser-search/config/.env.local ps

2. Check Typesense health:
   curl http://localhost:8108/health

3. Check recent logs:
   tail -50 ~/caser-search/logs/feed-scan.log

4. Check systemd services:
   systemctl --user status caser-scan@0.service --no-pager
   systemctl --user status caser-scan@1.service --no-pager
   systemctl --user status caser-monitor.service --no-pager
   systemctl --user status caser-backup.service --no-pager

5. Check all timers:
   systemctl --user list-timers | grep caser

6. Restart everything:
   cd ~/caser-search && docker compose --env-file config/.env.local restart
   systemctl --user restart caser-scan@0.timer caser-scan@1.timer
   systemctl --user restart caser-monitor.timer

7. If scanner fails with 401 errors:
   - Verify config/.env.local has correct TYPESENSE_ADMIN_KEY
   - Restart Docker: docker compose --env-file config/.env.local restart
   - Reload systemd: systemctl --user daemon-reload

8. If system doesn't auto-start on boot:
   - Check linger: loginctl show-user $USER | grep Linger
   - Enable if needed: sudo loginctl enable-linger $USER

9. Check backups:
   ls -lh ~/caser-search/backups/
   systemctl --user status caser-backup.timer --no-pager
